洛谷P1115 最大字段和

题目

求出一段长度为n的序列a，选出其中连续且非空的一段使得这一段的和最大

思路

1.贪心

我们可以袈裟当前的数为一段的最后一个数，那么无论如何都不可以跳过前一个数去选更前面的数

因为是从左到右扫描序列，因此前一个数为一段结尾的最有答案我们已经求出来了，如果前一段结尾，最优的区间和也不大于零，那么我们加上前面那一段不会更优

如果前一段的区间数大于零，那么可以弄一个更优解

cpp
int n;
int ans=-999;
int main()
{
	std::ios::sync_with_stdio(false);
	cin>>n;
	int sum=0;
	for(int i=1;i<=n;i++)
	{
		int a;
		cin>>a;
		sum+=a;
		ans=max(ans,sum);
		if(sum<0) sum=0;
	}
	cout<<ans<<endl;
	return 0;
}

P1719 最大加权矩形

题目

给定一个n*n的矩阵，请问其中最大的子矩阵的和为多少？n<=120

思路

直接枚举左上角，再枚举右下角成为一个矩形，直接用二维前缀和暴力就可以了，时间复杂度为O(n4)O(n^4)O(n4),这里我更加优化了一下

cpp
#include <iostream>
#include <cstdio>
#include <algorithm>
#include <cstring>
#include <string>
using namespace std;
int n;
int ans,a[125][125];
int main()
{
	std::ios::sync_with_stdio(false);
	cin>>n;
	for(int i=1;i<=n;i++)
	{
		for(int j=1;j<=n;j++)
		{
			cin>>a[i][j];
			a[i][j]+=a[i-1][j];
		}
	}
	for(int i=1;i<=n;i++)
	{
		for(int k=1;k<=i;k++)
		{
			int b[150]={0};
			int f[150]={0};
			for(int j=1;j<=n;j++)
			{
				b[j]=a[i][j]-a[i-k][j];
				f[j]=max(f[j-1]+b[j],b[j]);
				ans=max(ans,f[j]);
			}
		}
	}
	cout<<ans<<'\n';
	return 0;
}

不是所有的水都叫农夫山泉，不是只有序列和矩阵能做前缀和

树也是可以做前缀和的

意思是某个节点到根节点的路径上，经过的所有点的权值和

1.如果一个节点减去它的祖先的父亲的前缀和，就得到了这个点到达祖先的链的前缀和

2.如果两个点的前缀和加起来，再减去lca的前缀和，再减去lca的父亲的前缀和，就可以得到两点之间路径的前缀和，妙啊~

树上的路径跟序列还是有点不一样的，要先减lca再减lca他爸

原理也是容斥原理

题目

给你一个树，树上有n个节点，每个边有一个权值，给任意两个点，问两点之间路径边权的异或和是多少

思路

实际上，按照之前的思路，要求异或两次lca，但由于lca异或两次等于没有异或，所以两个的前缀和直接异或就可以了（因为是边权的前缀和

cpp
#include <iostream>
#include <cstdio>
#include <algorithm>
#include <cstring>
#include <string>
using namespace std;
const int maxn=100010;
int n,m;
struct edge{
	int e,next,val;
}ed[maxn*2];
int en,first[maxn];
void add_edge(int s,int e,int val)
{
	en++;
	ed[en].next=first[s];
	first[s]=en;
	ed[en].e=e;
	ed[en].val=val;
}
int s[maxn];
void dfs(int x,int fa,int w)
{
	s[x]=s[fa]^w;
	for(int i=first[x];i;i=ed[i].next)
	{
		int e=ed[i].e,w=ed[i].val;
		if(e!=fa)
		dfs(e,x,w); 
	}
}
int main()
{
	cin>>n;
	for(int i=1;i<=n-1;i++)
	{
		int x,y,z;
		cin>>x>>y>>z;
		add_edge(x,y,z);
		add_edge(y,x,z);
	}
	dfs(1,0,ed[1].val);
	cin>>m;
	for(int i=1;i<=m;i++)
	{
		int u,v;
		cin>>u>>v;
		cout<<(s[u]^s[v])<<'\n';
	}
	return 0;
}

快速区间加

快速区间加是结合前缀和和差分来进行的加速技巧

如果对于差分序列中某一个元素加上一个数字，那么这个加上的数会累计到后面的所有数

因此，我们可以利用这个特性，做一个快速区间加法

就是说对于b[i]+cb[i]+cb[i]+c,相当于给a[i]a[i]a[i]后面的所有的数都加了一个c

因此我们对于b[l]+cb[l]+cb[l]+c,b[r+1]−cb[r+1]-cb[r+1]−c，这样一前一后相互抵消，这样就能做出来[l,r][l,r][l,r]的区间加法了

离散化

离散化和离散实际上没有什么关系

离散化本质实际上是吧一系列数值用另一系列数值来代替

常见的一个应用就是把大数映射到小数

主要是因为在某些问题中，数值可能会很大，但是有用的数值并不多，因此可以用1—n来表示原来的n个数字，使之大小关系不变，方便进行操作

in fact 我们还可以把实数来映射到整数上，来简化操作

做法

首先识别关键数据，也就是要明确要映射哪些数据

然后将这些数据装到数组b里面，不需要考虑他们的顺序

然后对b排序，这个时候b可能存在重复的数据，然而，这些数据不利于操作，所以还需要进行去重操作，得到没有重复的数组c

如果对于一个关键数据，想要查询它映射之后的id，我们可以用一个二分查找

因为c中的数据各不相同，且保证关键数据一定在c内，因此查找id的二分非常好写

P1102 A-B数对

题目

给你一个序列以及一个数字c，问序列中差为c的数对的个数（不同位置但是数值一样的数算不同的数对)

思路

可以用桶诶？

但是好像值域太大了诶qwq

那？离散化？

不不不

这样就不能方便找到差距为c的数自乐

但是我们可以使用双指针来找到这个差距为c的数对

由于离散化的数组是递增的，因此枚举比较小的那个数，大的那个数的位置一定是递增的，如果大的数不存在，那么就让指针停在比大的数大的数上，总之右边指针的位置一定随着左边的增加而增加

有这个性质，我们就可以让两个指针同时从第一个数出发，只要指针指的数字之差小于c，就让右指针不断增加，知道大于等于C或者超出序列的范围

如果等右指针递增完毕，发现左右之差等于C，就可以统计答案了

这时候就用到离散化，用c[i]c[i]c[i]来表示第iii个数的数值，d[i]d[i]d[i]表示数值为c[i]c[i]c[i]的数有多少个，然后d[l]∗d[r]d[l]*d[r]d[l]∗d[r]即为答案

cpp
int main()
{
    cin>>n>>m;
    for(int i=1;i<=n;i++)
        cin>>a[i];
    for(int i=1;i<=n;i++)
        b[++btop]=a[i];
    sort(b+1,b+btop+1);
    b[0]=-2000000007;
    for(int i=1;i<=btop;i++)
        if(b[i]!=b[i-1])
            c[++ctop]=b[i];
    for(int i=1;i<=n;i++)
        d[search(a[i])]++;
    long long ans=0;
    for(int i=1,j=1;i<=n&&j<=n;i++)
    {
         while(j<=n&&c[j]-c[i]<m)
            j++;
        if(c[j]-c[i]==m)
            ans+=(long long)d[i]*d[j];
    }
    cout<<ans<<endl;
    return 0;
}

P3143 Diamond Collector

题目

有n个钻石，每一个钻石有一个闪亮度，现在让你挑选一些钻石放在两个盒子里，要求：

1.任意两个位于相同盒子的钻石的闪亮度之差不能超过k

2.两个盒子的数量之和最大

思路

没有思路

双指针

首先 对原序列排序

然后发现，如果两个钻石放在同一个盒子中，那么这两个钻石中间的也可以放在同一个盒子中

那么问题实际上是要找出两个不相交的区间，那么最大值和最小值的差都小于k，且区间长度之和最大

我们可以默认区间是不相交的，如果是相交的区间，那么一定可以吧一个区间的一部分花费给另外一个区间，这样就又是不相交的了

由于两个区间互相不影响，因此直接离散化做两次就可以了，第一次的结果储存在f数组中，f[i]f[i]f[i]表示以右端点小于i的所有方案的最优值，然后统计答案的时候统计r−l+1+f[l]r-l+1+f[l]r−l+1+f[l]就可以了

先考虑一个区间怎么做

二分也可以做

我们找右端点的过程，实际上满足二分的单调性，所以我们也可以用二分来做

cpp
#include <iostream>
#include <cstdio>
#include <algorithm>
#include <cstring>
#include <string>
using namespace std;
const int maxn=50005;
long long n,k; 
int a[maxn],f[maxn];
int main()
{
	std::ios::sync_with_stdio(false);
	cin>>n>>k;
	for(int i=1;i<=n;i++)
	cin>>a[i];
	sort(a+1,a+n+1);
	for(int i=1,j=1;i<=n&&j<=n;i++)
	{
		while(j<=n&&a[j]-a[i]<=k)
		{
			j++;
			f[j]=max(f[j],j-i);
		}
	}
	for(int i=1;i<=n;i++)
	f[i]=max(f[i],f[i-1]);
	int ans=0;
	for(int i=1,j=1;i<=n&&j<=n;i++)
	{
		while(j<=n&&a[j]-a[i]<=k)
		j++;
		ans=max(ans,f[i]+j-i);
	}
	cout<<ans<<endl;
	return 0;
}

P1638 逛画展

题目

给你n幅画，每幅画有一个画师，总共有m个画师，让你选择一个区间[a,b][a,b][a,b],使得把区间内的画看完了之后能看过所有画师的画，要求区间的长度最小，如果有多个解，输出a更小的区间

思路

尺取法

随着左端点的递增，右端点也递增

因为有可能左端点增加1个，导致某个画师的画没了，因此右端点必须向右把他找回来

所以这道题目的做法和上一题也比较相似，枚举左端点，每当左端点加1，就不断右移右端点，直到所有的画师都被包含位置

判断画师是不是被包含可以用桶

d[i]d[i]d[i]表示画师i在区间中出现的次数，然后在用cnt统计画师的数量

踢走一个画师的时候d[k]−−d[k]--d[k]−−，之后该变量等于0，cnt++

右端点右移的时候方式比较类似

cpp
#include <iostream>
#include <cstdio>
#include <algorithm>
#include <string>
#include <cstring>
using namespace std;
long long n,m;
long long a[1000005],b[2005];
long long cnt;
long long ans,l,r,ll,rr;
int main()
{
	std::ios::sync_with_stdio(false);
	cin>>n>>m;
	for(int i=1;i<=n;i++)
	cin>>a[i];
	l=1,r=1,cnt=1,b[a[1]]=1,ans=999999999;
	while(l<=r&&r<=n)
	{
		if(cnt==m)
		{
			if(ans>r-l+1)
			{
				ans=r-l+1;
				ll=l,rr=r;
			}
			b[a[l]]--;
			if(b[a[l]]==0)
			cnt--;
			l++;
		}
		else
		{
			r++;
			b[a[r]]++;
			if(b[a[r]]==1) cnt++;
		}
	}
	cout<<ll<<" "<<rr<<endl;
	return 0;
}
