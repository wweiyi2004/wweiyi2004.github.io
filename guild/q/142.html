T2 天天爱跑步

思路

Day1T2就这个难度了？ 恐慌

首先这是一棵树

我们可以按照顺序模拟，也就是一堆人在走路

如果是树的话，平均下来深度是 lognlog nlogn 的，那么有 mmm 个人，时间复杂度就是 O(mlogn)O(mlog n)O(mlogn) ，但是数据范围中提到了，这棵树可能会退化成一条链，这样时间复杂度就变成了 O(nm)O(nm)O(nm) ，显然时间复杂度会爆炸

所以我们想，正解肯定不是直接模拟（这还用说

然后我们发现，实际上我们可以转换一个角度，从观察员的角度进行思考

我们要看的就是对于每个观察员结点，有多少个结点在第 wjw_jwj​ 秒可以到达观察员结点

我们枚举观察员就是 dfs 一整棵树的过程，时间复杂度 O(n)O(n)O(n)

然后我们想，对于一个观察员有哪些结点会为他做贡献呢？

我们分类讨论对于一个观察员结点P在一条路径上的情况，其中起点为 sss ，终点为 ttt

  1. PPP 在 sss 到 lcalcalca 的路上

可以画一下，如果起点 sss 满足 dep[s]=w[P]+dep[P]dep[s]=w[P]+dep[P]dep[s]=w[P]+dep[P] ，这样这个起点这个结点就会为 PPP 产生一个贡献

  1. PPP 在 lcalcalca 到 ttt 的路上

同样可以画一下

我们可以定义 dis(i,j)dis(i,j)dis(i,j) 表示 从 iii 出发到 jjj 的路径长度

所以我们可以得到

dis(s,t)−w[P]=dep[t]−dep[P]dis(s,t)-w[P]=dep[t]-dep[P]dis(s,t)−w[P]=dep[t]−dep[P]

=dis(s,t)−dep[t]=w[P]−dep[P]=dis(s,t)-dep[t]=w[P]-dep[P]=dis(s,t)−dep[t]=w[P]−dep[P]

当终点满足上式的时候，终点会为 PPP 做一个贡献

我们发现，不管怎么样，为 PPP 能做贡献的结点一定在 PPP 的子树上

递归以 PPP 为根的子树的时候，可以统计出来子树中所有起点和终点对他的贡献

但是我们发现，子树中有些起点和终点对 PPP 产生了贡献，有些没贡献

桶的用法我是真不懂草

然后就寄了

然后如果 PPP 和起点或者终点重合的话，这个贡献会重复计数一次，所以要减一

	ed[en].e=e;
}

void dfs1(int x)
{
	for(int i=1;(1<<i)<=dep[x];i++)
	fa[x][i]=fa[fa[x][i-1]][i-1];
	for(int i=first[x];i;i=ed[i].next)
	{
		int e=ed[i].e;

int get_lca(int x,int y)
{
	if(x==y) return x;
	if(dep[x]<dep[y]) swap(x,y);
	int t=log(dep[x]-dep[y])/log(2);
	for(int i=t;i>=0;i--)
	{
		if(dep[fa[x][i]]>=dep[y])
		x=fa[x][i];
		if(x==y)
		return x;
	}
	t=log(dep[x])/log(2);
	for(int i=t;i>=0;i--)
	{
		if(fa[x][i]!=fa[y][i])
		x=fa[x][i],y=fa[y][i];
	}
	return fa[x][0];
}

然后按照普通的动态规划做

思路

首先，看到这道题目，我想到了大根堆

每次取出堆顶，按照题意进行模拟，然后把得到的蚯蚓放回来，然后其他的蚯蚓都加 qqq

T3 愤怒的小鸟

思路

搜索，或者状压

如果是我这种蒟蒻的话

搜索更好理解一些

我们可以对于当前小鸟，尝试搜索这只小鸟是否在已有的抛物线上

如果在的话，说明这个小鸟不用再多占一个抛物线，所以直接退出

如果不在的话，我们就要考虑这个小鸟和当前其他还没有匹配的小鸟是不是可以组成一个抛物线

如果横坐标相同，显然不行，因为函数是一一对应的映射

然后用公式算一个函数 y=ax2+bxy=ax^2+bxy=ax2+bx 的 a,ba,ba,b

推导一下：

设函数上两点 (x1,y1),(xx,y2)(x_1,y_1),(x_x,y_2)(x1​,y1​),(xx​,y2​)

则
{ax12+bx1=y1①ax22+bx2=y2②\begin{cases} ax_1^2+bx_1=y_1 ① \\ ax_2^2+bx_2=y_2② \end{cases}{ax12​+bx1​=y1​①ax22​+bx2​=y2​②​①×x2−②×x1①\times x_2-② \times x_1①×x2​−②×x1​ 得
a(x12x2−x22x1)=y1x2−y2x1a(x_1^2x_2-x_2^2x_1)=y_1x_2-y_2x_1a(x12​x2​−x22​x1​)=y1​x2​−y2​x1​
移项
a=y1x2−y2x1x12x2+x22x1③a= \dfrac {y_1x_2-y_2x_1} {x_1^2x_2+x_2^2x_1}③a=x12​x2​+x22​x1​y1​x2​−y2​x1​​③③③③ 带入 ①①① 或者 ②②②

如果 a<0a<0a<0 说明可以构成抛物线，所以我们将这个抛物线加入，把这个猪删除，然后搜索，然后回溯

{

{
	if(cnt+re>=ans) return ;

	{
		ans=cnt+re;
		return ;
	}
	bool flag=false;
	for(int i=1;i<=cnt;i++)

		if(check(pa[i]*x[dep]*x[dep]+pb[i]*x[dep],y[dep]))
		{
			dfs(dep+1,cnt,re);
			flag=true;
			break;
		}
	}
	if(!flag)
	{
		for(int i=1;i<=re;i++)
		{
			if(check(x[dep],dx[i])) continue;
			double a=(y[dep]*dx[i]-dy[i]*x[dep])/(x[dep]*x[dep]*dx[i]-dx[i]*dx[i]*x[dep]);
			double b=(y[dep]-x[dep]*x[dep]*a)/x[dep];
			if(a<0)
			{
				pa[cnt+1]=a;
				pb[cnt+1]=b;
				double p=dx[i],q=dy[i];
				for(int j=i;j<re;j++)
				{
					dx[j]=dx[j+1];
					dy[j]=dy[j+1];
				}
				dfs(dep+1,cnt+1,re-1);
				for(int j=re;j>i;j--)
				{
					dx[j]=dx[j-1];
					dy[j]=dy[j-1];
				}
				dx[i]=p,dy[i]=q;
			}
		}
		dx[re+1]=x[dep],dy[re+1]=y[dep];
		dfs(dep+1,cnt,re+1);
	}
}
int T;
int main()
{
	cin>>T;
	while(T--)
	{
		cin>>n>>m;
		for(int i=1;i<=n;i++)
		cin>>x[i]>>y[i];
		ans=10000;
		dfs(1,0,0);
		cout<<ans<<'\n';
	}
	return 0;
}
