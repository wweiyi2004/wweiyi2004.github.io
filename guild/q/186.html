在 专题（二） 里，SuperGlue / LightGlue 是把两张图的描述子重新配对。但很多时候（比如用 SIFT、ORB、SuperPoint 做完最便宜的最近邻粗配后），我们手里已经有了一批初始候选匹配对（Putative Correspondences）：

C={ ci=(xi,yi,xi′,yi′) }i=1N∈RN×4C = \big\{\, \mathbf{c}_i = (x_i, y_i, x'_i, y'_i) \,\big\}_{i=1}^{N} \in \mathbb{R}^{N \times 4} C={ci​=(xi​,yi​,xi′​,yi′​)}i=1N​∈RN×4

（通常先用相机内参把像素坐标归一化到归一化相机平面，每个匹配对就是一个 4 维向量。）

麻烦在于，这些粗糙候选里经常有 70%～90% 都是乱连的假匹配（外点，Outliers）。直接扔给经典 RANSAC 算本质矩阵 EEE，外点率一高，RANSAC 要迭代几万次才可能凑齐 8 个全对的点，既慢又容易算飞。

误匹配剔除网络（Correspondence Pruning / Outlier Rejection） 就插在“粗匹配”和“几何估计”之间，干两件事：

  • 输入：NNN 对含大量外点的无序坐标 [B, N, 4]（例如 N=2000N = 2000N=2000），网络必须满足置换等变性（打乱 NNN 行顺序，输出结果对应打乱）；
  • 输出：① 每对匹配的内点置信度权重 wi∈[0,1]w_i \in [0, 1]wi​∈[0,1]（[B, N]）；② 用可微加权八点法（Weighted 8-Point）算出的本质矩阵 EEE（[B, 3, 3]）；③ 推理时把筛干净的内点送入 RANSAC 精估位姿。

先认识共同的基础组件：可微加权八点法（Weighted 8-Point）

后面四篇论文在训练结尾几乎都会用到同一个数学工具——可微加权八点法，我们先花 30 秒把它彻底看明白：

  • 对于任意一对真匹配（归一化齐次坐标 x~i=(xi,yi,1)⊤\tilde{\mathbf{x}}_i = (x_i, y_i, 1)^\topx~i​=(xi​,yi​,1)⊤ 和 x~i′=(xi′,yi′,1)⊤\tilde{\mathbf{x}}'_i = (x'_i, y'_i, 1)^\topx~i′​=(xi′​,yi′​,1)⊤），本质矩阵 E∈R3×3E \in \mathbb{R}^{3\times 3}E∈R3×3 必须满足对极约束 x~i′⊤Ex~i=0\tilde{\mathbf{x}}'^\top_i E \tilde{\mathbf{x}}_i = 0x~i′⊤​Ex~i​=0；
  • 把 EEE 展平为 9 维向量 e\mathbf{e}e，每对匹配都能写成一行 9 维约束向量 ϕi⊤e=0\boldsymbol{\phi}_i^\top \mathbf{e} = 0ϕi⊤​e=0，全部 NNN 对堆成一个 N×9N \times 9N×9 矩阵 Φ\PhiΦ；
  • 给每行乘上网络预测的内点权重 wiw_iwi​，构成加权矩阵 Φ~=diag⁡(w)Φ\tilde{\Phi} = \operatorname{diag}(\mathbf{w}) \PhiΦ~=diag(w)Φ，求最小二乘解：

最早的开山工作 CNe / LFGC（CVPR 2018） 照搬 PointNet，用 MLP + Context Normalization（CN） 迈出了第一步，但它既抓不到局部邻域，又容易被 80% 的外点污染统计量。本专题四篇论文正是一步步把这两个坑填平：

下面我们逐篇拆开公式和张量流。

1. OANet：可微软聚类成“有序小组”，补齐局部与全局交互

论文：Learning Two-View Correspondences and Geometry Using Order-Aware Network（ICCV 2019）

1.1 为什么说无序点集没法直接做“空间混合”？

假设输入是 N=2000N = 2000N=2000 对候选匹配，经过逐点 MLP 后特征形状是 [B, 2000, 128]。
在传统 CNe 里，每个点各自独立过 1×1 卷积，点与点之间唯一一次交流就是沿 N=2000 维求全局均值和标准差（Context Normalization）。

那为什么不能直接沿 N=2000 维加一个全连接层让点互相交流呢？因为输入的 2000 个点是无序的！ 如果你直接给第 1 个点和第 2 个点配固定权重，一旦把输入顺序打乱，输出就全乱套了（破坏了置换等变性）。

1.2 核心三明治模块：DiffPool → Order-Aware Filtering → DiffUnpool

OANet 用一个极其巧妙的三步结构，在不破坏置换等变性的前提下，硬生生造出了“有固定顺序的局部簇”：

重点体会一下它的两重魔力：

  1. 数学上严格满足置换等变性：假设把输入行顺序按置换矩阵 Π\PiΠ 打乱变成 ΠFin\Pi F_{\mathrm{in}}ΠFin​，那么 SSS 变成 ΠS\Pi SΠS，UUU 变成 ΠU\Pi UΠU。你看聚类结果 (ΠS)⊤(ΠFin)=S⊤(Π⊤Π)Fin=S⊤Fin(\Pi S)^\top (\Pi F_{\mathrm{in}}) = S^\top (\Pi^\top \Pi) F_{\mathrm{in}} = S^\top F_{\mathrm{in}}(ΠS)⊤(ΠFin​)=S⊤(Π⊤Π)Fin​=S⊤Fin​ 完全不变！最后反聚类 (ΠU)Fc′=ΠFout(\Pi U) F'_c = \Pi F_{\mathrm{out}}(ΠU)Fc′​=ΠFout​，输出严格跟着输入同步置换！
  2. 自然抓到局部上下文：几何位置和运动规律相近的点会被分到同一个簇里，先在簇里抱团，再和别的簇全局对话。

1.3 迭代精修与联合损失

OANet 实际还用了两阶段迭代架构（OANet++）：

  1. 第一阶段 OANet 吃进 [N, 4] 原始坐标，预测出初步内点权重 w(1)\mathbf{w}^{(1)}w(1)，用可微加权八点法算出初步本质矩阵 E(1)E^{(1)}E(1)；
  2. 拿 E(1)E^{(1)}E(1) 算出每对匹配当前的对称极线距离（几何残差）ri(1)r_i^{(1)}ri(1)​，把它和初步权重 wi(1)w_i^{(1)}wi(1)​ 一起拼回原始 4 维坐标（变成 [N, 6]），喂给第二阶段 OANet 再精细过滤一次，吐出更准的最终权重 w(2)\mathbf{w}^{(2)}w(2) 和 E(2)E^{(2)}E(2)！

总训练损失由内点分类损失 + 本质矩阵几何损失两部分组成：

L=Lcls(w,y)+β Lgeom(E^,Egt)L = L_{\mathrm{cls}}(\mathbf{w}, \mathbf{y}) + \beta \, L_{\mathrm{geom}}(\hat{E}, E_{\mathrm{gt}}) L=Lcls​(w,y)+βLgeom​(E^,Egt​)

（其中 LclsL_{\mathrm{cls}}Lcls​ 用对极距离小于阈值如 10−410^{-4}10−4 标出来的真值标签做加权二元交叉熵；LgeomL_{\mathrm{geom}}Lgeom​ 用虚拟采样点计算估计本质矩阵 E^\hat{E}E^ 与真值 EgtE_{\mathrm{gt}}Egt​ 的对称极线误差。）

2. ACNe：把 80% 假匹配踢出归一化统计量！

论文：ACNe: Attentive Context Normalization for Robust Permutation-Equivariant Learning（CVPR 2020）

2.1 用一个极简数值例子看穿普通 CN 的硬伤

假设一个场景里只有 10 个真匹配（特征值稳稳落在 1.0 左右），却混进了 90 个假匹配（特征值乱飞，均值在 10.0 左右、标准差很大）。

传统的 Context Normalization（CN）对所有 N=100N=100N=100 个点一视同仁求均值和方差：

μ=1N∑i=1Nfi,σ=1N∑i=1N(fi−μ)2,CN(fi)=fi−μσ\mu = \frac{1}{N}\sum_{i=1}^{N}\mathbf{f}_i, \qquad \sigma = \sqrt{\frac{1}{N}\sum_{i=1}^{N}(\mathbf{f}_i - \mu)^2}, \qquad \mathrm{CN}(\mathbf{f}_i) = \frac{\mathbf{f}_i - \mu}{\sigma} μ=N1​i=1∑N​fi​,σ=N1​i=1∑N​(fi​−μ)2​,CN(fi​)=σfi​−μ​

算出来的 μ≈9.1\mu \approx 9.1μ≈9.1，完全被那 90 个垃圾外点绑架了！于是那 10 个本来很一致的真匹配一减均值、一除大标准差，全被压扁挤到角落里，特征分布彻底崩坏。

2.2 核心模块：Attentive Context Normalization（ACN）

ACNe 的改法极其克制、极其锋利：别再等权平均了，给每个点算一个“靠谱权重 wiw_iwi​”，用加权均值和加权方差来做归一化！

具体怎么算这个权重 wiw_iwi​？ACNe 拆成了局部权重 + 全局权重两条并行支路：

注意为什么不能只留 Softmax 全局权重，或者只留 Sigmoid 局部权重？

  • 如果只有 Softmax：当整张图里真匹配很多（比如 500 个）或极少（比如 10 个）时，Softmax 强制总和为 1，容易出现过度集中在少数几个点或给外点分残余概率的问题；
  • 如果只有 Sigmoid：缺少全局横向比较，面对两批“各自看起来还行”的冲突匹配簇时没法择优；
  • 两者相乘再归一化：既能由局部 Sigmoid 干净地把外点清零，又能由全局 Softmax 在内点里排出主次！

关键训练细节（逐层深度监督）：在训练时，ACNe 不只是在最后一层算损失，而是把每一层 ACN 块里算出来的局部权重 wilocw_i^{\mathrm{loc}}wiloc​ 都拉出来，直接用真值内点/外点标签算二元交叉熵损失！这样从第一层开始，外点就被死死摁住，压根进不了后面的归一化统计量。

3. LMCNet：把“运动平滑一致”写成图拉普拉斯闭式可微层

论文：Learnable Motion Coherence for Correspondence Pruning（CVPR 2021）

3.1 物理直觉：把匹配画成一张“位移箭头场”

前面两篇都是纯特征统计视角。LMCNet 重新挖出了几何视觉里最朴素的一条规律：运动一致性（Motion Coherence）。

把每对候选匹配写成“起点位置 xi=(xi,yi)\mathbf{x}_i = (x_i, y_i)xi​=(xi​,yi​) + 位移向量（运动）mi=(xi′−xi, yi′−yi)\mathbf{m}_i = (x'_i - x_i, \, y'_i - y_i)mi​=(xi′​−xi​,yi′​−yi​)”。在真实拍摄的两张照片里：

  • 空间上挨得很近的真匹配，因为处在同一个连续表面上，它们的位移箭头 mi\mathbf{m}_imi​ 在方向和长度上高度平滑一致；
  • 假匹配的位移箭头往往横冲直撞，和周围邻居格格不入。

以前的传统方法（如 VFC、GMS）直接拿手工核函数在原始坐标上做平滑，一碰到稀疏点分布不均或者参数没调好就失效。LMCNet 把“平滑运动拟合”搬进深度特征空间，并把它推导成了一个闭式可微的图拉普拉斯层！

3.2 整体架构与全局运动一致性层推导

第一步：在 NNN 个候选匹配上建图

给定当前层特征 X∈RN×CX \in \mathbb{R}^{N \times C}X∈RN×C 和原始坐标，算出任意两对匹配 i,ji, ji,j 之间的亲和度 WijW_{ij}Wij​（空间越近、特征越像，亲和度越高；对角度矩阵 Dii=∑jWijD_{ii} = \sum_j W_{ij}Dii​=∑j​Wij​），于是得到图拉普拉斯矩阵：

L=D−W∈RN×NL = D - W \in \mathbb{R}^{N \times N} L=D−W∈RN×N

第二步：写出“平滑去噪”的能量优化目标

我们希望从含噪特征 XXX 里解出一份干净、平滑的新特征 Y∈RN×CY \in \mathbb{R}^{N \times C}Y∈RN×C，既不能离原始观测 XXX 太远（保真项），又要让图上相连节点的特征尽量平滑一致（平滑项）：

min⁡Y  ∥Y−X∥F2+α∑i,jWij∥yi−yj∥22=∥Y−X∥F2+2αTr⁡(Y⊤LY)\min_{Y} \; \|Y - X\|_F^2 + \alpha \sum_{i, j} W_{ij} \|\mathbf{y}_i - \mathbf{y}_j\|_2^2 = \|Y - X\|_F^2 + 2\alpha \operatorname{Tr}(Y^\top L Y) Ymin​∥Y−X∥F2​+αi,j∑​Wij​∥yi​−yj​∥22​=∥Y−X∥F2​+2αTr(Y⊤LY)

第三步：对 YYY 求导令其为 0，直接拿到闭式解！

这个二次凸优化问题连迭代都不需要，一步求导就能写出闭式解：

Y∗=(I+2αL)−1XY^* = (I + 2\alpha L)^{-1} X Y∗=(I+2αL)−1X

第四步：用谱分解低频截断，既加速又天然滤掉外点！

直接求 N×NN \times NN×N（如 2000×20002000\times 20002000×2000）矩阵的逆既慢又耗显存。LMCNet 把对称半正定的归一化拉普拉斯矩阵做特征分解 L=UΛU⊤L = U \Lambda U^\topL=UΛU⊤，并利用图信号处理的低通滤波性质：

  • 特征值 λk\lambda_kλk​ 越小的特征向量 uk\mathbf{u}_kuk​，代表图上变化越平缓的全局低频运动模式（对应真实的相机刚体运动）；
  • 特征值越大的特征向量，代表剧烈震荡的高频跳变（对应乱飞的假匹配外点！）。

因此，LMCNet 只保留前 KKK 个最小特征值对应的低频基 UK∈RN×KU_K \in \mathbb{R}^{N \times K}UK​∈RN×K（例如 K≪NK \ll NK≪N），闭式平滑层瞬间化简为高效的矩阵乘法：

Y∗≈UK diag⁡ ⁣(11+2αλk)UK⊤XY^* \approx U_K \, \operatorname{diag}\!\left(\frac{1}{1 + 2\alpha \lambda_k}\right) U_K^\top X Y∗≈UK​diag(1+2αλk​1​)UK⊤​X

（直观理解：这一步就像把带杂音的录音送进低通滤波器，高频杂音（外点）被直接削平，干净的全局主旋律（真匹配运动场）被完整提取出来！最后再把原特征 XXX 和平滑后的 Y∗Y^*Y∗ 拼在一起对比——和全局平滑场差异特别大的点，八成就是外点！）

3.3 配合局部运动一致性层

除了全局图拉普拉斯层，LMCNet 在每一层还并联了一个局部运动一致性层（Local Coherence Layer）：在每个点的 kkk 近邻小圈子里做带权局部图卷积（类似 EdgeConv），专门捕捉小物体边缘和局部细节。两者一全局一局部拼接起来，再接残差更新，最后同样送进分类头和可微加权八点法输出本质矩阵 EEE。

4. ConvMatch：跳出 PointNet 套路，直接用经典 CNN 修运动场！

论文：ConvMatch: Rethinking Network Design for Two-View Correspondence Learning（AAAI 2023）

4.1 为什么说“用 CNN 处理无序匹配”是个降维打击？

回顾前面三篇：OANet 写 DiffPool、ACNe 写加权统计、LMCNet 写图拉普拉斯谱分解……大家之所以绞尽脑汁，都是默认了一个前提：“候选匹配是无序点集，所以只能基于 PointNet/MLP 硬改”。

ConvMatch 提出了一个极其清爽的逆向思考：

每对匹配 (xi,yi)→(xi′,yi′)(x_i, y_i) \to (x'_i, y'_i)(xi​,yi​)→(xi′​,yi′​) 其实就是图像平面上某个位置 (xi,yi)(x_i, y_i)(xi​,yi​) 处采样到的一个 2D 位移向量！既然如此，把所有稀疏匹配向量投射回一张规整的 Hg×WgH_g \times W_gHg​×Wg​ 二维网格（隐式稠密运动场），不就能直接用最成熟、天然擅长抓局部空间上下文的 CNN 了吗？

4.2 一步步追踪 ConvMatch 的“稀疏 → 稠密 → 稀疏”张量流

注意 ConvMatch 为什么既满足置换等变、又特别快？

  • 第一步把 NNN 个无序点聚到固定 16×1616 \times 1616×16 网格上时，是对 NNN 维做加权求和，所以无论输入顺序怎么打乱，生成的 16×1616\times 1616×16 特征图一模一样；
  • 第二步的所有卷积全都跑在极小的 16×16 网格上，算力开销小得惊人，而且 CNN 天然自带平移等变性和局部归纳偏置，比靠 MLP/注意力从零硬学空间邻域轻松得多！

5. 总结：四篇误匹配剔除论文的核心差异与选型

  1. OANet：如果你想理解怎么在无序点集上用“可微聚类 + 反聚类”构造有序全局交互，以及两阶段极线残差迭代框架，OANet 是必读基石；
  2. ACNe：改动最轻巧，点破了高外点率下归一化统计量被污染的要害，其“局部 Sigmoid + 全局 Softmax 加权统计”技巧可以无缝移植到各种点云/集合网络里；
  3. LMCNet：理论最优雅，把几何里的运动平滑先验直接翻译成可微图拉普拉斯低通滤波层，物理直觉极强；
  4. ConvMatch：架构最简洁高效，跳出 PointNet 思维定势，用“隐式稠密运动场 + CNN / 双边卷积”实现了极高的精度和速度平衡。

到这里，先找点 → 再匹配 / 剔外点的整套稀疏生态就讲圆满了。下一篇 专题（四）：无检测器半稠密匹配，我们直接扔掉关键点检测器，看 LoFTR → QuadTree → TopicFM → ELoFTR → EDM 是如何在弱纹理和白墙里也能密密麻麻配出成千上万对点的！
